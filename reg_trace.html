Critical Points

🔴 ID Confusion Can Occur Here

  • authUserId vs elderId: Different UUIDs
    • authUserId = supabase.auth.user.id (from Auth, for Storage RLS)
    • elderId = elder_profiles.id (from DB, for FaceEnrollment)
    • Storage path uses authUserId; DB row uses elderId
  • If elderId is local uid(): FaceEnrollment rejects it (line 154–160)
  • If profileId mismatch: Registration aborts before face modal

🔴 Where Supabase Errors Happen Most

  • RLS Failures (HTTP 403/42501): Migrations not run
  • Storage RLS (HTTP 400/403): Path segment mismatch or policy missing
  • NULL Constraint (HTTP 23502): profiles.email not nullable
  • Anonymous Auth Disabled: Supabase Dashboard Provider setting not configured
  • elder_profiles row missing: INSERT succeeded but SELECT returns nothing (race condition or RLS)
